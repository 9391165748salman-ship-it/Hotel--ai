# 🏨 HotelAI – AI-Powered Smart Hotel Service Platform

## 📌 About the Project

HotelAI is an AI-powered smart hotel service and coordination platform designed to improve communication and coordination between hotel guests, staff, and management.

The platform helps automate hotel service requests, streamline staff coordination, and provide an intelligent digital experience for guests.

---

## 🚀 Key Features

* 🤖 AI-powered Hotel Assistant
* 🛎️ Smart Service Request Management
* 👥 Staff Coordination System
* 📊 Hotel Management Dashboard
* 🔔 Real-Time Service Notifications
* 🏨 Guest Service Automation
* ⚡ Faster Response and Improved Operational Efficiency

---

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/9391165748salman-ship-it/Hotel--ai.git
```

### 2. Navigate to the Project Folder

```bash
cd Hotel--ai
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```
